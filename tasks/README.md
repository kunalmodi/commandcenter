# Tasks

One Markdown file per task, named `NNN-slug.md`, with a small header:

```
---
id: 007
title: Verify imsg send flags on the Mac
status: todo        # todo | doing | done
area: imsg
created: 2026-11-04
---

Free-form notes below. `bin/task note` appends dated lines.
```

Use `bin/task` (run `bin/task help`), or edit the files directly; both work.
